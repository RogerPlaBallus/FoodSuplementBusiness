# VERA CATALONIA — Clean Daily Supplements SPA

## Authorship
- Made by **Roger Pla Ballús** with **Gemini 2.5 Pro**

## Stack
- **Markup:** Semantic HTML5 (`<dialog>`, native form validation)
- **Styling:** Tailwind CSS v4 (CDN) + flat multi-color cards (`0` glow/shadow payload)
- **Typography:** `Syne` (display) + `DM Sans` (body)
- **Logic & Graphics:** Vanilla ES2024 JavaScript + Inline Vector SVG supplement bottles (`0` external dependencies)

## Architecture
- **Single-File Storefront (`index.html`):** Zero build step, zero runtime dependencies.
- **Pure Functions:** Integer-cent cart billing (`calculateBagTotals`), EFSA-bounded dosage math (`computeRoutine`), and regex postal sanitizer (`sanitizePostal`).
- **Self-Verifying Runtime:** Embedded 5-assertion unit test suite runs on page load.

## Core Aspects
- **Modern Supplement Storefront UI:** Custom SVG apothecary bottles, distinct color palettes per formula, and 2-bullet product summaries.
- **Catalan Bio-Provenance:** Formulas sourced from Pyrenees peaks, Montseny, Empordà, Priorat, Reus, and Cap de Creus.
- **20-Second Routine Finder:** Calculates daily dosages and recommends a 2-bottle pair with a 15% bundle discount.
- **Zero Repetition:** Single Girona HQ & laboratory contact bar.

## Install / Run
- **Clone:** `git clone <repo-url> && cd <repo-folder>`
- **Download:** Save `index.html` directly.
- **Run:** Open `index.html` in any browser or run `npx serve .`
